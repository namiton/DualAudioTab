DualAudioTab v1.0.2
==================================================

ブラウザの音だけを、ミキサーと自分の耳へ。ずれなく同時に届ける
Chrome 拡張機能です。

YouTube・配信サイト・Web 音楽プレーヤーなど、ブラウザで流している音だけを、
「ミキサー（オーディオインターフェース）の入力」と「自分のヘッドホン」へ
同時に、タイミングを揃えて送ります。
選んだタブの音だけを送るので、PC のほかの音（通知音やボイスチャットの声）は
混ざりません。


■ こんな使い方に
--------------------------------------------------
・配信：ブラウザの音をミキサーで配信に乗せつつ、自分はヘッドホンでモニター
・カラオケ・歌ってみた：音源を聴きながら、ミキサーでマイクの声と混ぜる
・録音：Web の音源をオーディオインターフェースへ送りつつ、手元でも聴く
・ボイスチャット・VRChat：マイクと一緒にブラウザの音も流す


■ できること
--------------------------------------------------
・タブの音を 2 系統（A / B）の出力デバイスへ同時に再生
  例）A：ヘッドホン　B：ミキサーやオーディオインターフェースの入力
  （タブ本来の再生はミュートされ、二重には鳴りません）
・出力ごとに音量・追加遅延・ミュートを設定
  （− / + ボタンで 1% / 1 ms 単位の微調整。長押しで連続）
・各デバイスの出力遅延の差を自動で補正し、A/B のタイミングを揃える
・設定は自動保存され、次回も引き継がれる
・外部への通信なし。録音・保存もしません


■ 動作環境
--------------------------------------------------
・Google Chrome 116 以降
・ミキサー側へ送るには、PC から音を出力できる機器
  （オーディオインターフェース、USB ミキサー、VB-CABLE などの仮想オーディオデバイス）


■ インストール
--------------------------------------------------
1. この zip を展開する（展開した DualAudioTab フォルダは消さずに置いておく）
2. Chrome のアドレスバーに chrome://extensions と入力して開く
3. 右上の「デベロッパー モード」を ON にする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、
   展開した DualAudioTab フォルダを選ぶ
5. ツールバーのパズルアイコンから DualAudioTab をピン留めしておくと便利です


■ 初回だけ: 出力デバイスの許可
--------------------------------------------------
既定以外の出力デバイスを選ぶには、拡張機能への許可が必要です。
ポップアップ下部の「デバイス名を表示」を押し、開いたページで「許可する」を
押してください。
Chrome の仕様で「マイク」の許可として求められますが、マイクの音は使いません。


■ 使い方
--------------------------------------------------
1. 音を出したいタブで DualAudioTab のアイコンを押し、「開始」を押す
2. A / B の出力デバイス・音量（VOL）・追加遅延（DLY）を設定する
3. 取り込み中のタブは、黄色のタブグループ「DualAudio」に入り、
   ツールバーのアイコンが点灯（バッジ「ON」）します。止めるときは同じタブで「停止」

・同時に取り込めるのは 1 タブです。別のタブで「このタブに切替」を押すと移ります
・タブを閉じると自動で停止します
・自動補正後もずれる機器（Bluetooth 等）は、DLY で手動調整してください
・Chrome を再起動した後は、もう一度「開始」を押してください


■ 更新方法
--------------------------------------------------
以前に読み込んだ DualAudioTab フォルダの中身を新しいものに差し替え、
chrome://extensions で DualAudioTab の更新ボタン（⟳）を押してください。
設定は引き継がれます。


■ アンインストール
--------------------------------------------------
chrome://extensions で DualAudioTab の「削除」を押してください。


■ 注意
--------------------------------------------------
・出力機器そのものの遅延（数十 ms 程度）はなくせません。本ソフトは 2 つの出力の
  ずれを揃えるもので、遅延をゼロにするものではありません。
・ミキサーの音をヘッドホンにも返している場合、ブラウザの音が二重に聞こえることが
  あります。その場合はミキサー側のモニター設定で調整してください。
・ミキサーや仮想ケーブル経由で配信・通話に流している場合、取り込んだタブの音は
  相手にも聞こえます。音源の利用は各サービスの規約と著作権のルールに従ってください。
