# DualAudioTab

Chrome のタブの音を 2 つの出力デバイスへ同時に鳴らす拡張機能。
VRChat などで「自分のヘッドホン」と「仮想ケーブル／別スピーカー」へ同じ音を同時に流す用途を想定。

## 特徴

- タブの音を 2 系統（A / B）の出力デバイスへ同時再生。タブ本来の再生はミュートされ二重に鳴らない
- 出力ごとに音量・追加遅延・ミュートを設定
- 各デバイスが報告する出力遅延の差を自動補正して A/B を揃える
- 外部通信なし。取り込んだ音は PC 内の出力デバイスへ流すだけで、録音・保存はしない

## インストール

1. このリポジトリをダウンロード（Code → Download ZIP を展開、または `git clone`）
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを選ぶ
4. ツールバーのパズルアイコンからピン留めしておくと使いやすい

Chrome 116 以降が必要。

## 初回だけ: デバイス名の許可

既定以外の出力デバイスを選ぶには、拡張機能にマイク許可が必要（Chrome の仕様。マイク音は使わない）。
ポップアップ下部の「デバイス名を表示」→ 開いたページで「許可する」。

## 使い方

1. 音を出したいタブでアイコンを押し、ポップアップの「開始」
2. A / B の出力デバイス・音量（VOL）・追加遅延（DLY）を設定。設定は自動保存
3. 取り込み中のタブにはバッジ `ON` が付く。止めるときは同じタブで「停止」

- 同時に取り込めるのは 1 タブ。別タブで「このタブに切替」を押すと移る
- タブを閉じると自動で停止
- 自動補正後もずれる機器（Bluetooth 等）は DLY で手動調整

## 権限

| 権限 | 用途 |
|---|---|
| `tabCapture` | アイコンを押したタブの音を取り込む |
| `offscreen` | ポップアップを閉じても再生を続けるための非表示ページ |
| `storage` | 出力デバイス・音量・遅延の設定保存 |
| `activeTab` | ポップアップにタブ名を表示 |

## 仕組み

- `popup.js`: `chrome.tabCapture.getMediaStreamId` で取り込み ID を取得（アイコン操作が必要）
- `background.js`: offscreen ドキュメントの生成・破棄、バッジ、タブ終了時の停止
- `offscreen.js` + `audio-core.js`: ID からタブ音声を取得し、`sinkId` 違いの `AudioContext` 2 つへ分配。報告遅延の差を DelayNode で自動補正

## 確認用スクリプト

```bash
node test/load-check.mjs <使い捨てプロファイルのパス> [screenshot.png]
node test/capture-check.mjs <使い捨てプロファイルのパス>
```

使い捨てプロファイルの Chrome に拡張を読み込み、service worker 起動・ポップアップ表示・開始命令の伝達・出力処理を確認する。
取り込み開始そのものはアイコン操作が必須のため自動化していない。
